Download one zip file with everything your firm keeps in Coil. Use it to keep your own copy, to move to another system, or to run Coil yourself.

  • Every table as a spreadsheet (CSV) that opens in Excel.
  • The complete database, which restores into a self-hosted Coil.
  • Every uploaded document, with an index of which matter and client each belongs to.
  • Your settings and customizations: invoice template, tools, matter and letter templates, appearance and workflows.
  • Generated PDFs, a README that explains each folder, and a manifest with a fingerprint for every file.

Coil checks the file before you get it: every file present and unchanged, the database intact, and the row counts matching. A firm with many documents can take a few minutes. Keep this page open until the download starts.

Store the file securely. It holds confidential client information. The spreadsheets leave out passwords, keys and client links, but the database file is kept whole, so it contains everyone's sign-in credentials in hashed form and any integration keys saved in Settings.
